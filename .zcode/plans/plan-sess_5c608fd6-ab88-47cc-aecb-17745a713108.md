## 三、触发方式优化（按需加载）

当前问题：agent 定义文件中的通用防御段（规则 5/6/8）在每个文件中重复，且 agent 被派发时整个文件加载。

### 3.1 建立 `_common-rules.md` 共享引用

在 `.claude/agents/_common-rules.md` 中写一次通用规则，各 agent 文件只保留差异部分 + 一行引用：
```
> 通用规则见 `_common-rules.md`，以下仅列本 agent 差异。
```

效果：每个 agent 文件减少 6-8 行样板段，且规则修改只需改一处。

### 3.2 Knowledge 按需加载（已是 consult 模式）

knowledge 文件已经是 `troubleshooter` 按需 consult 读取，不需要改动。

### 3.3 Playbooks 按需加载（已是 consult 模式）

playbooks 已经是 agent 遇到问题时按需读取，不需要改动。

### 3.4 Rules 按需读取

rules/*.mdc 文件通过 Cursor 的 globs 机制自动匹配，已是最优触发方式。

### 3.5 Context 按需读取

context/ 文件已由 `fe-common-utils.md` 提供关键词索引，agent 按需 Read 具体文件。
