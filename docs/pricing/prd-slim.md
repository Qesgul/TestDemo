# AI生图-智能生图提示词模板扩充 (精简版)

> 精简时间：2026-07-16
> 模块数：8 | 需求条数：42 | 发现歧义：2 处

---

## 模块1：气泡提示（登录且非空状态）

- **触发条件**：用户已登录 + 进入智能生图页面
- **展示位置**：全部模板按钮下方
- **内容**：标题"模板库升级"，正文"内容扩充，更多选择；支持收藏、新建、搜索"，按钮"查看"/"知道了"
- **关闭规则**：
  - 点击"查看" → 关闭气泡 + 展开全部模板，后续不再展示
  - 点击"知道了" → 关闭气泡，后续不再展示
  - 点击"全部模板"展开 → 关闭气泡，后续不再展示
  - 点击输入框输入文本 → 关闭气泡，次日符合条件继续展示
    - 当天后续主动点击"全部模板"展开 → 视为已触达，后续不再展示
    - 当天未点击"全部模板" → 次日再次展示
- **累计上限**：同一用户最多展示3次
- **后端**：建表存储记录，接口供前端判断

## 模块2：横幅提示（未登录/空状态）

- **触发条件**：未登录 或 已登录但无历史生图记录
- **展示内容**：横幅"模板库升级：内容扩充，更多选择；支持收藏、新建、搜索"，按钮"查看"/"知道了"
- **关闭规则**：
  - 点击"查看" → 关闭横幅 + 展开全部模板，后续不再展示
  - 点击"知道了" → 关闭横幅，后续不再展示
  - 点击"探索更多"展开 → 视为已触达，后续不再展示
- **累计上限**：未登录状态最多展示3次

## 模块3：输入框

- 引导文案：`请输入您的需求或 使用模板 →`
- "使用模板 →"使用主题色，点击展开全部模板（同"全部模板"按钮）

## 模块4：全部模板

- **新增元素**：左侧"我的模板"栏、底部"新建模板"按钮、顶部"搜索框"
- **模板交互**：鼠标移入模板 → 右上角显示收藏/删除按钮
- **官方模板**：支持收藏/取消收藏
  - 未收藏点击 → 判断登录 → 未登录弹注册登录弹窗 / 已登录收藏并变状态
  - 已收藏点击 → 判断登录 → 未登录弹注册登录弹窗 / 已登录取消收藏并变状态
- **个人模板**：仅支持删除
  - 鼠标移入显示删除按钮
  - 点击删除 → 判断登录 → 未登录弹注册登录弹窗 / 已登录弹确认弹窗
  - 确认弹窗文案："确认要删除该模板吗？删除后将无法恢复！"
  - 确认 → 删除 + 卡片自动补位；取消 → 关闭弹窗

## 模块5：搜索模板

- **搜索框**：引导文案"搜索模板"，聚焦后输入内容隐藏文案
- **输入限制**：上限50字，超出toast"超出最大输入长度"
- **搜索范围**：官方模板 + 该用户个人模板
- **搜索方式**：按模板名称、模板内容关键词
- **排序规则**（总得分 = 名称得分 + 内容得分）：
  - 名称完全一致：100分
  - 名称包含完整搜索词：80分
  - 名称部分命中关键词：每命中1个20分，最高60分
  - 内容包含完整搜索词：30分
  - 内容命中关键词：每命中1个5分，最高20分（去重后计）
  - 总得分相同 → 按最近使用/收藏/新建时间倒序
- **防抖**：300ms，输入>=1字符进入待搜索，停止300ms触发，继续输入重新计时，空不触发
- **结果展示**：当前浮窗内，标题改为"搜索结果"
- **结果非空**：个人模板有"我的"标签
- **结果为空**：展示"未找到相关模板"/"换个关键词试试"/"创建自己的模板 →"
  - 点击"创建自己的模板 →" → 判断登录后弹新建模板弹窗

## 模块6：我的模板

- **内容**：仅展示该用户已收藏/创建的模板
- **排序**：按最近使用/收藏/新建时间（越新越靠前）
- **空状态/未登录**：展示"暂无个人模板"/"查看热门模板"/"新建模板"
  - 点击"查看热门模板" → 定位到"热门"
  - 点击"新建模板" → 判断登录后弹新建模板弹窗

## 模块7：新建模板

- **必填项**：模板内容、模板名称（有必填标识）；封面非必填
- **引导文案**：模板内容"请输入模板内容"，模板名称"请输入模板名称"
- **输入支持**：ctrl+v粘贴文本，清空后重新显示引导文案
- **高度溢出**：上方内容被遮挡，右侧出现滑动条
- **字数限制**：模板内容上限2000字，模板名称上限50字，超出toast
- **保存校验**：
  - 必填项缺失 → toast"请输入模板名称/模板内容"
  - 敏感信息 → toast"含有敏感信息 XXX，XXX，XXX"
  - 通过 → toast"创建成功"，如在"我的模板"下立即刷新列表
- **取消**：关闭窗口，内容不保存
- **关闭按钮**：
  - 3处均无内容 → 直接关闭
  - 任一处有内容 → 弹出"关闭后当前内容将丢失，是否确认关闭？"，确认关闭/取消返回
- **封面上传**：
  - 支持资源管理器选择 + ctrl+v粘贴
  - 校验顺序：格式(jpg/jpeg/png) → 大小(50KB~20MB) → 分辨率(高或宽≤30000px，总像素≤2.5亿) → 敏感信息
  - 校验通过 → 上传中状态 → 完成后显示缩略图
  - 鼠标移入缩略图 → "重新上传"/"删除"按钮
- **展示**：保存后与官方模板一致，鼠标移入仅有删除按钮
- **无封面**：显示默认封面
