# 测试点分析报告

> 需求来源：AI生图-智能生图提示词模板扩充-PRD
> 生成时间：2026-07-16
> 预计用例数：78 条

---

## 一、需求概述

本需求为AI智能生图功能的提示词模板库扩充，核心目标包括：新增气泡/横幅升级提示引导用户触达模板库、扩充模板交互能力（收藏/删除/搜索/新建）、新增个人模板管理功能。主要面向建筑/室内/景观领域用户，通过降低提示词编写门槛提升使用率。

---

## 二、模糊点与澄清建议

> 以下问题建议在测试开始前与产品/开发确认：

| # | 模糊点描述 | 澄清建议/问题 |
|---|-----------|-------------|
| 1 | 模块2中"空状态"定义不明确——是"从未使用过智能生图"还是"当前无可用模板"？ | 建议与产品确认"空状态"的判定条件：是否需要后端记录用户历史生图次数 |
| 2 | 模块7封面上传校验顺序：格式不合规时是否继续校验大小和分辨率？ | 建议确认是否按顺序逐级校验，遇到第一个不合规即停止并toast |
| 3 | 搜索结果排序中"最近使用时间"的定义——是用户点击模板的时间还是使用模板生图的时间？ | 建议明确"使用"的埋点触发时机 |
| 4 | 模块4中"全部模板"浮窗展开/收起的具体交互方式未说明（点击展开/收起，还是hover？） | 建议确认交互方式 |
| 5 | 个人模板删除后是否可恢复？PRD提到"删除后将无法恢复"但未说明是否有回收站机制 | 建议确认是否有软删除/回收站 |
| 6 | 新建模板的"敏感信息校验"是前端校验还是后端校验？校验时机是保存时还是实时？ | 建议明确敏感词校验的技术实现方式 |

## 三、测试点清单

### 模块1：气泡提示（登录且非空状态）

#### TP-01 气泡展示条件与内容

- **设计方法**：场景法 / 等价类划分
- **测试点**：
  - [ ] 已登录用户首次进入智能生图页面，气泡正确展示
  - [ ] 气泡标题、正文、按钮文案正确
  - [ ] 未登录用户不展示气泡
  - [ ] 已登录但非空状态（有历史记录）展示气泡
- **风险提示**：气泡展示条件需后端接口配合，需关注接口异常时的降级策略

#### TP-02 气泡关闭行为

- **设计方法**：场景法 / 判定表
- **测试点**：
  - [ ] 点击"查看"→ 关闭气泡 + 展开全部模板 + 后续不再展示
  - [ ] 点击"知道了"→ 关闭气泡 + 后续不再展示
  - [ ] 点击"全部模板"展开 → 关闭气泡 + 后续不再展示
  - [ ] 点击输入框输入文本 → 关闭气泡，次日符合条件继续展示
  - [ ] 输入文本后当天再点击"全部模板" → 后续不再展示
  - [ ] 输入文本后当天未点击"全部模板" → 次日再次展示
- **风险提示**：次日逻辑依赖日期判断，需关注跨天/时区边界

#### TP-03 气泡展示次数上限

- **设计方法**：边界值分析
- **测试点**：
  - [ ] 气泡累计展示1次、2次，符合条件时继续展示
  - [ ] 气泡累计展示3次后，不再展示
  - [ ] 不同关闭方式均计入展示次数
- **风险提示**：需确认"累计展示"是否包含被输入文本关闭的情况

### 模块5：搜索模板

#### TP-12 搜索框基础交互

- **设计方法**：等价类划分
- **测试点**：
  - [ ] 搜索框引导文案为"搜索模板"

  - [ ] 输入内容后引导文案隐藏
  - [ ] 清空内容后引导文案恢复

#### TP-13 搜索输入限制

- **设计方法**：边界值分析
- **测试点**：
  - [ ] 输入49字 → 正常输入
  - [ ] 输入50字 → 正常输入，达到上限
  - [ ] 输入51字 → toast"超出最大输入长度"
  - [ ] 输入特殊字符（emoji、标点）→ 正常处理
- **风险提示**：中文字符与英文字符的字数计算是否一致（1中文=1字？）

#### TP-14 搜索防抖机制

- **设计方法**：场景法 / 边界值分析
- **测试点**：
  - [ ] 输入1个字符 → 停止300ms → 自动触发搜索
  - [ ] 快速连续输入 → 300ms内继续输入 → 取消上次搜索，重新计时
  - [ ] 搜索框为空 → 不触发搜索
  - [ ] 输入后快速清空 → 不触发搜索
- **风险提示**：防抖时间精度，不同设备性能下的表现差异

#### TP-15 搜索结果展示

- **设计方法**：场景法 / 等价类划分
- **测试点**：
  - [ ] 搜索结果在当前浮窗内展示
  - [ ] 顶部标题改为"搜索结果"
  - [ ] 搜索结果非空时，个人模板有"我的"标签
  - [ ] 搜索结果为空时展示：未找到相关模板/换个关键词试试/创建自己的模板
  - [ ] 点击"创建自己的模板"→ 判断登录 → 弹出新建模板弹窗
  - [ ] 搜索范围包含官方模板和个人模板

#### TP-16 搜索排序规则

- **设计方法**：场景法 / 判定表
- **测试点**：
  - [ ] 名称完全一致 → 排序最高（100分）
  - [ ] 名称包含完整搜索词 → 排序第二（80分）
  - [ ] 名称部分命中关键词 → 每命中1个20分，最高60分
  - [ ] 内容包含完整搜索词 → 30分
  - [ ] 内容命中关键词 → 每命中1个5分，最高20分
  - [ ] 总得分相同 → 按时间倒序
- **风险提示**：排序算法的准确性需结合实际数据验证
