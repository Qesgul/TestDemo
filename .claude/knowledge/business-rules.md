# 核心业务规则

> 最后更新：2026-06-25
> 这里只记录「不看PRD也应该知道的」产品通用规则；需求特有规则仍在各自PRD里。
> 计价明细（知币/知点具体价格）**不在此维护**，以PRD为准，防止过时误导。

## 素材业务线：通用规则

### 下载标准流程节点
```
付费素材详情页 → 触发下载确认弹窗 → 券优先级选中 → 金额计算 → 知币扣减 → 下载
```
- **强一致要求**：详情页展示价格 == 弹窗支付金额 == 实际扣减知币，三点必须完全一致
- 关闭弹窗（X按钮）：不下载、不扣费、不产生任何记录

### VIP身份判定
- 通过 `member_level` 字段判定（非VIP / 个人VIP各等级 / 企业VIP）
- VIP相关优惠（VIP立减、抵扣券膨胀）独立于非VIP计费链路，二者不可混用
- 非VIP误展示 VIP立减 / "待激活"文案 = P1缺陷

### 下载抵扣券通用规则
- 无可用券时：整行"下载抵扣券"字段不展示（含"不使用"选项也不展示）
- 单选框选中/取消券：金额**实时重算**，无缓存脏数据
- 多张券并存：单选互斥（选一张其余自动取消）
- **VIP的5知币券会膨胀**，非VIP持有时不膨胀、不被优先默认

### 每日下载限额
- VIP用户每日下载上限存在（具体值以PRD为准），自然日 0 点重置
- 超限时提示"今日下载超限"，不产生错误扣减

## AI绘图业务线：通用规则

### 知点扣减时机
- 知点在**提交任务时**扣减，不是任务完成时
- 任务失败 / 超时：**不额外扣费**
- 知点不足：提示余额不足并引导充值，不产生错误扣减、不提交任务

### 新老用户权益保护（通用原则）
- **新用户**（指定天数内无使用记录）：调价后立即按新价
- **老用户（当前权益期内）**：保原价到本期结束，续费/新充值后按新价
- 新旧用户边界天数以各PRD为准（已见过365天）

## 登录态规则

### 知末网登录弹窗操作顺序（必须按顺序，否则输入框不渲染）
1. 点「手机」tab
2. 点「账号密码登录」
3. 填手机号
4. 填密码
5. 提交
6. 等登录弹窗消失

### 跨子域 session 规则
- `.com` 各子站（www/su/sgt/3d）：CAS登录后共享session；但 `su` 需额外独立UI登录
- `ai.znzmo.cn`：与所有 `.com` 子站完全隔离，CAS无效，需独立 storage_state
- storage_state 缓存：`.auth/<domain>_state.json`，12小时有效

### 账号锁定
- 错误密码多次会锁号 15–30 分钟；锁定即停手，不反复试
- 凭据必查 `tests/data/account_pool.yaml`，禁止凭记忆
