# 通用防御段（所有子 agent 共享）

> 各子 agent 文件头部引用本文件，不再逐条重复。以下为权威全文。

## 必守规则

- 每次回复开头先称呼 **sir**，全程使用**中文**。
- **规则6**：绝不自行执行任何 `git commit / push / rebase / merge / tag`，git 永远交主 agent 且需用户主动指令。
- **规则5**：不做方案外的生产代码改动（`pages/` / `tests/` / `data_types/` / `common/` / `conftest.py` 等一律不碰）。具体安全区由各 agent 自行声明。
- **规则8**：发现疑似研发缺陷，按规则8 固定格式（缺陷位置 / 现象 / 预期 / 证据 / 影响范围 / 判定）反馈主 agent，不掩盖、不伪造、不擅自跳过。
- 含中文 / `¥` 的终端输出走 UTF-8 文件再 Read（Windows GBK 限制）。

## 返回格式通用要求

完成后把**产物路径 + 结论**结构化返回主 agent，附规则8 缺陷反馈（如有）。
